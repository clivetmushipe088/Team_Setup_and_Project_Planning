# Scrum Board Setup

The Scrum board is a GitHub Project with **Todo**, **In Progress** and **Done** columns.

## Create the board

1. Go to [github.com/clivetmushipe088?tab=projects](https://github.com/clivetmushipe088?tab=projects) and click **New project**.
2. Under **Start from scratch**, pick **Board**, name it `MoMo SMS Analytics Scrum Board` and click **Create project**.
3. Open **⋯ → Settings** (top right), scroll to **Danger zone** and change **Visibility** to **Public**.
4. In the repository, open the **Projects** tab, click **Link a project** and choose the board.

## Tasks

Add each task with **+ Add item** at the bottom of its column.

| Column | Task |
|--------|------|
| Done | Create GitHub repo and README |
| Done | Set up project folder structure |
| Done | Draw system architecture diagram |
| In Progress | Set up Scrum board |
| In Progress | Research the MoMo SMS XML format |
| Todo | Parse and clean the XML data |
| Todo | Categorize transactions and load them into SQLite |
| Todo | Build the dashboard (charts and table) |

## Add the link to the README

Copy the board URL (for example `https://github.com/users/clivetmushipe088/projects/1`) and replace the placeholder link in the README's **Scrum board** section.
